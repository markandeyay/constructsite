## Decisions and assumptions

1. **Font family token names.** The spec fixes the three families but not the
   token names. Coded against `--font-display`, `--font-body`, `--font-mono`.
   Logged as a cross-WP request to WP-02.
2. **`.site-header__link--contact`.** Spec 7.0 collapses the nav to Contact only
   below 720px, with no hamburger and no drawer. Doing that without a `:not()`
   chain (banned by 18.3) or a fragile `nth-child` needs a marker on the Contact
   anchor. Requested and coded against `.site-header__link--contact`. Logged as
   a cross-WP request to whoever authors `src/sections/header.ts`.
3. **Section shell selector.** `index.html` did not exist when this package ran,
   so the shell rhythm is attached to both `main > section` and `.section`. The
   shells get the correct padding whether or not WP-01 adds a class.
4. **Title opacity.** `.sec-head__title` is never hidden by this stylesheet. If
   WP-08's per word reveal does not run, the heading is still readable. WP-08
   owns any initial opacity on the title's word spans.
5. **Breakpoints** are only 600, 720, 900 and 901, written as literal px. No
   custom property appears in a media query condition.
6. **Header is opaque.** No `backdrop-filter`, no `--paper-a92`. Spec 2.4 bans
   glassmorphism and 7.0 explicitly declines the exception.
7. **Footer has no email address**, per override A4. Styled for a GitHub link
   and a year only.

## Gates

- No `!important`, no `:not()` styling chain, no bare `img` selector in either
  stylesheet.
- No gradient of any kind, no glow, no colored `box-shadow`, no
  `backdrop-filter`, no marquee, no custom cursor, no emoji.
- No em dash in any comment or string in any file this package wrote.
- No personal name, no `PMR`, no `PlasmidAI` anywhere in these files.
- Brace balance verified in all three stylesheets.
- `qa/components-gallery.html` renders every component against the real
  `tokens.css`, `base.css`, `layout.css` and `components.css` with no copied
  values.
