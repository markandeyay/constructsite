## Decisions

1. **seqviz types are adequate, so `declare module 'seqviz'` was NOT written.**
   `node_modules/seqviz/package.json` points `types` at `dist/index.d.ts`, which
   declares the vanilla entry as
   `Viewer(element: (string | HTMLElement) | undefined, options: SeqVizProps)`
   returning `{ render, renderToString, setState } | undefined`. That is exactly
   the `Viewer(el, opts)` shape section 8.4 uses. A probe file importing
   `Viewer` typechecks clean under `strict` with `skipLibCheck: true`. Adding an
   ambient stub would have shadowed those real types with `any`.
   Note for WP-06: the declared first parameter is `HTMLElement`, not `Element`,
   so pass an `HTMLElement` (or narrow) or strict mode will reject it.
2. **`declare module '3dmol';` WAS written**, per deliverable 4 and spec section
   9.2, even though 3dmol 2.5.5 does in fact ship types at
   `build/types/index.d.ts` (the spec's claim that it ships none is stale). The
   ambient declaration wins for the `3dmol` specifier and yields `any`, which is
   what the contract asks for. WP-07 may narrow it.
3. `tsconfig.json` includes `src` and `vite.config.ts`, and excludes `qa`
   (the QA harness is `.mjs`, per section 16), `node_modules` and `dist`.
   `types: ["vite/client"]` is what makes the six `*.css` imports in `main.ts`
   typecheck.
4. `vite.config.ts` exports `SITE_ORIGIN` as a single obvious one-line constant
   with a comment marking it as the only place the domain is defined (contract
   C4). The inline `transformIndexHtml` plugin replaces every literal
   `%SITE_ORIGIN%` occurrence. Verified in an isolated sandbox build: the built
   `index.html` carries `https://constructsite.vercel.app/og-card.png` and zero
   remaining `%SITE_ORIGIN%` tokens.
5. `main.ts` mounts through a `mountInto(id, mod)` guard that returns silently
   when the shell is absent: no log, no throw. `ScrollTrigger.refresh()` runs
   after `document.fonts.ready`. Both reserved regions (WP-10, WP-15) are empty
   and sit inside `boot()`; the `gsap.matchMedia()` block belongs in the WP-10
   region.
6. `index.html` ships eight section shells (hero, problem, how, outputs,
   validation, structure, traction, contact), each with
   `aria-labelledby="<id>-title"`, plus `<header id="site-header">` and
   `<footer id="site-footer">` outside `<main id="main">`. No inline styles, no
   content, no email address, no banned strings.
